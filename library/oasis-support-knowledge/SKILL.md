# Support Knowledge

Keep topic facts and answering instructions aligned with the actual product
sources, UI and supported languages. Edit or register the requested material and
exercise relevant acceptance questions at the actual destination when available.
Use [support experience](references/best-practices.md) for source authority,
natural localized wording and model-answer evidence.
