# Published Content

Read the applicable [content experience](references/best-practices.md) before choosing an approach.
Use it for release drift,
managed-region ambiguity and uncertain connector writes.

Resolve the actual release and the intended page/document region, then update
that region from published facts and links. Preserve manual content and verify
the saved nesting and facts.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
