# Rendering Performance

Read the applicable [rendering experience](references/best-practices.md) before choosing an approach.
Use it for first-draw behavior,
context replacement, isolated preview reuse and native GPU limits.

Diagnose the actual rendering layer and measure the changed work while preserving
visual equivalence, bounds and resource lifetime. Compare relevant cold/reference
frames and supported poses.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
