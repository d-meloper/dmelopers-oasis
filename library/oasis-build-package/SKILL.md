# Build Package

Read the applicable [package experience](references/best-practices.md) before choosing an approach.
Use it for toolchain prerequisites,
output parity, store identities and candidate reuse.

Use the project's configured producer and target profile to build the requested
package, keeping exact inputs and complete outputs together. Reuse a compatible
retained candidate and recover partial builds from the affected stage.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
