# Dependency Security

Read the applicable [dependency experience](references/best-practices.md) before choosing an approach.
Use it for reachable usage,
replacement compatibility and incomplete scanner evidence.

Trace the requested dependency change through actual build/runtime use, affected
advisories and license/notices. Apply the project's security policy and refresh
the owning notice generator when relevant.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
