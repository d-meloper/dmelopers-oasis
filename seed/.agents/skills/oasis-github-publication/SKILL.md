# GitHub Publication

Prepare and execute the source or release delivery included in the request using
the project's configured destination. Carry one reviewed candidate through its
repository controls and verify the resulting public refs and artifacts. Consult
[publication experience](references/best-practices.md) and the
[project command references](../../../ProjectGuide.md#command-references) for exact-byte export,
drift and partial or uncertain recovery.
