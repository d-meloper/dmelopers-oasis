# GitHub Publication

Read the applicable [publication experience](references/best-practices.md) before choosing an approach.

Prepare and execute the source or release delivery included in the request using
the project's configured destination. Carry one reviewed candidate through its
repository controls and verify resulting public refs and artifacts. The
[project command references](../../../ProjectGuide.md#command-references) route
exact-byte export, drift and partial recovery.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
