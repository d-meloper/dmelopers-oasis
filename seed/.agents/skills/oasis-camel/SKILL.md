# Camel

Read the applicable [implementation experience](references/best-practices.md) before choosing an approach.

Investigate, implement and run relevant checks for the assigned goal. Use the
current task's project references. Use
[dependency waiting](../../../LocalGitWorkflow.md#dependency-waiting-and-resumption)
for blocked work. Submit changes, checks and result references through the
completion path; runtime delivers them to Cameleer after native turn completion
for collection and archival;
contact Cameleer during work for material scope changes or unresolved problems.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
