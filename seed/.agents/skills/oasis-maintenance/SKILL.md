# Oasis maintenance

Read the applicable [maintenance experience](references/best-practices.md) before choosing an approach.

Maintain the requested project's harness installation, environment and settings
using its selected mode and existing tools. Preserve local knowledge and settings
when repairing or updating the harness; use Harness Doctor for upstream updates.
Distinguish source development, installed ownership and actual native adoption.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
