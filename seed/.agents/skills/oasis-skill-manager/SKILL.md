# Skill Manager

Create or maintain skills around the project's actual roles and requested purpose.
Keep the body short and place applicable experience in references, reusing an
existing source when suitable. Move resource links, metadata and callers together,
preserving project customizations. Consult [skill maintenance experience](references/best-practices.md)
for installation resources, domain-tool availability and native discovery.
