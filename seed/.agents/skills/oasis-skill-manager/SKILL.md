# Skill Manager

Read the applicable [skill maintenance experience](references/best-practices.md) before choosing an approach.

Create or maintain skills around the project's actual roles and requested
purpose. Keep bodies short, retain applicable experience in its existing owner,
and move resource links, metadata and callers together. Preserve customizations
and distinguish installed resources, tool availability and actual discovery.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
