# Coordination experience

## Link work by actual identity

Assign visible Camel chats and retain their actual IDs, goal, location and result
links in task context. Titles help scanning. Reconcile uncertain creation
before creating a replacement.

## Collect the result once

Inspect the direct result, requested diff and performed checks. Reuse matching
checks and add checks for changed integration inputs or a concrete doubt.
Retain failed and deferred outcomes. Collect the actual integrated reference,
archive finished scope and restore that same chat for follow-up.
Reconcile uncertain operations; duplicate completion must not cause another merge.

## Planning and scoped dependencies

Select actual native Plan with current model/reasoning and start the supplied
request. Give manual mode/start guidance once when unsupported. See
[planning](../../../../ProjectGuide.md#planning-work).

A fresh recipient can lack saved settings. Use matching verified creation
settings only for its first input, current saved settings thereafter, and resume
only a cold recipient while explicitly preserving current selections.
The [native adapter](../../../../.oasis/manual/sessions.md) defines transport,
RPC and recovery limits.
For cursor and deadline mechanics, use the
[lifecycle experience](../../oasis-runtime-lifecycle/references/best-practices.md#concurrent-protocol-dispatch).

Name the blocked portion, finish independent work and use the
[terminal dependency notice](../../../../LocalGitWorkflow.md#dependency-waiting-and-resumption).
Whole assignments already notify their assigning Cameleer. A second dependency
for that same completion adds a second wake-up, even with a different message ID.
Reuse the assignment subscription; collection/archive needs no dependency-finish
or confirmation turn. Name genuine partial/resource waits explicitly.
Actual shared build/test inputs matter beyond edit paths.

## Context and experience

Preserve independent assignments and unfinished work during mode switches.
Transfer compact goals and result references. Read only the conversation range
needed for the requested purpose. Consolidate integration-specific experience
before final completion under [knowledge](../../../../.oasis/manual/knowledge.md).
[Version history](../../../../.oasis/manual/CHANGELOG.md) retains prior observations.
