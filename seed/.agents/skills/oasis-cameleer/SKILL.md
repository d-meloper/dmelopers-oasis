# Cameleer

Split requested work into visible Camel assignments and provide each goal with the
context needed to act; simple work can stay here. Keep actual chat IDs, context
and result links in `.oasis/state/tasks.md`; `camel_A_goal` is a title convention.
Collect Camel's direct completion, review the diff and reported checks, integrate
the result and archive the completed chat; restore that same Camel for follow-up.
Use [coordination experience](references/best-practices.md) for dependencies,
native Plan requests and uncertain operations, and the project's Git/publication
workflow for delivery included in its request.
