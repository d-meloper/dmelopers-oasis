# Git Operations

Carry out Git work and backup using the project's selected unmanaged, single-main
or main-test workflow. Coordinate overlapping checkout/index operations and keep
other writers' bytes. Consult [Git experience](references/best-practices.md) and the
[local Git workflow](../../../LocalGitWorkflow.md) for profile changes,
configured backups and uncertain push recovery.
