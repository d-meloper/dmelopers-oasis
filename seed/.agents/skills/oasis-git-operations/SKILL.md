# Git Operations

Read the applicable [Git experience](references/best-practices.md) before choosing an approach.

Carry out Git work and backup using the project's selected unmanaged,
single-main or main-test workflow. Coordinate overlapping checkout/index
operations and preserve other writers' bytes. Use the
[local Git workflow](../../../LocalGitWorkflow.md) for profile changes,
configured backups and uncertain push recovery.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
