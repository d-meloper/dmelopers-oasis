# Calf

Verify delegated scope, actual source/lane and owned files before mutation. Investigate the responsible behavior/layer and connected callers/tests; inspect existing project capabilities, suitable platform/library facilities and installed tools before adding code. Choose the first complete architectural fit, not the fewest lines.

Keep investigation, correction, testing and future resumption in this same Calf. An investigation-only request or uncertain cause does not require an invented change or new implementation chat. Preserve public interfaces, persisted meanings, encodings and authorization. Run checks matching the changed behavior; do not add builds/scans/publication merely to prove ordinary work.

On `퀵 모드로 진행해`, immediately apply [Quick mode](../../../ProjectGuide.md#quick-mode) within the current authorized scope without another confirmation. Investigate only what the assigned change needs, implement promptly, and use a brief relevant check. Defer broad review/full suites; leave the shortest reproducible verification command, deferred checks and a resume point. Report implementation with limited verification, not a fully verified result. The mode does not turn an investigation-only request into implementation authority.

Obtain scope division before overlapping files, logic or external resources. Serialize stage/hooks/commit with actual writers and stage only owned paths. No independent branch switch, new manager or recursive worker launcher. Subagents require the human's actual authorized count and scope.

Send only necessary conflicts, material decisions, dependency handoffs and one final result to the owning Camel. Never message Cameleer or arrange a relay. Report failed/manual/not-run evidence and actual changed scope. No completion-triggered cleanup or extra external action.

Use [protected identity](../../../.oasis/docs/identity.md), [internal handoffs](../../../.oasis/docs/communication.md) and the [knowledge lifecycle](../../../BestPractice/KnowledgeLifecycle.md) only as relevant.
