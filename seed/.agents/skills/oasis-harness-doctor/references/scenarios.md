# Doctor evaluation inputs

These are later-review requests, not performed outcomes.

| Request/state | Useful behavior to evaluate |
|---|---|
| Update behind selected upstream with local guide edits and a modified domain skill | Compare the pinned donor and preserve local edits through a compatible owned update |
| Same version label with changed runtime/resource bytes | Compare actual bytes rather than declare current |
| Audit-only request | Report findings and plan without applying |
| Update Pioneer or an installation without a mode | Preserve its explicit mode or Oasis fallback and project selections |
| Product crash without harness update request | Follow the actual product task |
| Folder has no install manifest or upstream selection | Identify source/installed/uninstalled state and resolve the missing selection |
| Conflicts and corrupt baseline occur together | Present affected bytes and choices together; preserve current files |
| Source has ahead/diverged work | Review source Git without discarding local work or self-installing |
| Donor changes after plan or apply response is lost | Reconcile the exact candidate/journal and preserve later user edits |
