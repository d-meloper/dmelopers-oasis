# Doctor experience

K25-K28 in the [migration reference](../../../../.oasis/manual/migration-lessons.md)
exercise stale preflight, lock ownership, interrupted installation and upstream
baseline versus local specialization. They support using the existing installer
transaction and preserving current local knowledge through three-way comparison.

An unchanged version string can still contain different source bytes. Compare
the complete pinned donor, and use version-delta notes to find affected areas
rather than substitute for the diff. K02/K29/K41 distinguish resource coverage,
active discovery and installed operating manuals.

For legacy Calf migration, let active Camel/Calf work finish, retain old chat and
task links, and transfer useful locally modified implementation knowledge into
Camel references before retiring the skill. Historical exact text remains a
reference; retired reporting/ACK procedures do not become new Camel requirements.
See [the workflow](workflow.md) for update plans and conflict handling.
