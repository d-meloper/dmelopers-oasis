# Harness Doctor

Inspect harness health and updates against the project's selected upstream,
comparing actual bytes and installed ownership. Apply compatible requested updates
through the installer while preserving settings, installed skills and accumulated
knowledge; surface unresolved material conflicts. Use the
[Doctor workflow](references/workflow.md) for acquisition, three-way updates and
legacy Calf migration, and [Doctor experience](references/best-practices.md) for
version drift and interrupted operations.
