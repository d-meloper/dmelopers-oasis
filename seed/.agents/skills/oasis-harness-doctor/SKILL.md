# Harness Doctor

Read the applicable [Doctor experience](references/best-practices.md) before choosing an approach.

Inspect harness health and updates against the selected upstream, comparing
actual bytes and ownership. Apply compatible requested updates through the
installer while preserving settings, skills and accumulated knowledge; surface
material conflicts. Use the [Doctor workflow](references/workflow.md) for
acquisition, three-way updates and interrupted-operation recovery.

Before the final completion report, consolidate useful lessons from this work
once in the owning experience reference.
